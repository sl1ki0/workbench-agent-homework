# Changelog

## 0.3.0

- Потоковая терминальная сессия с редактором, подсказками, переключателем режимов и статусом исполнения.
- Запуск из других директорий, настройки проектных скиллов и оценка размера инструкций.
- Управление MCP, проверка соединений и поиск в официальном реестре.
- Расширенный набор evals, маркетплейс с контролируемыми обновлениями и откатом, локальный GUI.

## 0.2.0

- Подключаемые скиллы с каталогом и загрузкой инструкции по запросу модели.
- Stdio MCP с отдельным списком разрешённых функций чтения и учебным трекером.
- Офлайн-доктор сессии, статистика активаций и вызовов, отдельная доступность данных usage.
- Протокол, фикстуры, проверки и агрегатор для воспроизводимой оценки A/B.

## 0.1.0

- Собственный TypeScript runtime для задач в учебном workspace.
- Сессии, tool calling, policy, подтверждения, восстановление, бюджеты, план и задачи.
- Терминальный диалог, OpenAI-compatible API, просмотр правок и откат.

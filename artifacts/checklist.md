Сводка указывает результаты, выбор, usage, ошибки и ссылки на журналы.                | [Программные проверки результата](../eval/checks), [тест возобновления](../test/eval.test.ts). Манифест, принятое решение и детерминированные тесты принятия, отклонения и отката. | [Eval правила обновления](../src/market/gate.ts), [версии progress-summary](../market-fixtures/skills/progress-summary), [детерминированные тесты](../test/market-gate.test.ts). ## Приёмка результатов

- [x] README содержит уровень, зависимости, команды запуска, модель и режим, конфигурацию и схему логов. Репозиторий публичный.
- [x] [A/B](ab/report.md) содержит 30 уникальных `session_id` и 30 уникальных `run_id`. Журналы доступны для всех попыток, включая ошибки. В сводке разобраны пары A/B и сформулирован вывод по гипотезе.
- [x] [Сравнение обновления](update/report.md) содержит 30 уникальных сессий и run ID. Параметры, два SHA-256 версии, критерии, артефакты, журналы и решение сохранены.
- [x] [Отчёт доктора](doctor/findings.txt) привязан к реальному JSONL. Правила проверены на проблемных и нормальных примерах.
- [x] [События рынка](update/discovery/market-events.jsonl) содержат время, источник и результат проверки, хеши скиллов и сообщение об ошибке при наличии. Снимки показывают новый скилл и обновление ранее установленного.
- [x] [Скриншоты](screenshots/README.md) показывают интерактивную работу терминала и GUI.
- [x] `npm run check` проходит. Команда `node artifacts/verify.mjs` проверяет сохранённые материалы без ключей автора.

Для сценария защиты используйте [уровни 4–10](../docs/live-levels.md) и [пошаговый терминальный маршрут](../docs/defense.md).

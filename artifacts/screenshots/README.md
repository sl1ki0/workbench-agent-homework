# Скриншоты интерактивной работы

GUI снят в браузере. Терминальный ряд показывает вывод настоящего TUI, запущенного в PTY. Оба диалога используют локальную модель и настоящий MCP, при этом у каждого свой workspace и журнал.

| Интерфейс | Кадр                                                                                             | Что показано                                                                               |
| --------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| TUI       | [10 · Skills](10-terminal-skills.png)                                                            | Интерактивный список, поиск и размер инструкций.                                           |
| TUI       | [11 · MCP](11-terminal-mcp.png)                                                                  | Состояние соединения и доступные инструменты.                                              |
| TUI       | [12 · Задача](12-terminal-task.png)                                                              | Агент получает данные MCP и сохраняет отчёт.                                               |
| TUI       | [13 · Уточнение](13-terminal-follow-up.png)                                                      | Агент читает результат, отвечает и показывает статистику сессии.                           |
| TUI       | [14 · Доктор](14-terminal-doctor.png)                                                            | Разбор сохранённых событий и расход по двум запускам.                                      |
| TUI       | [15 · Очередь](15-terminal-queue.png), [16 · Thinking](16-terminal-thinking.png)                 | Второе сообщение ждёт своей очереди, первая задача получает сигнал thinking от провайдера. |
| GUI       | [01 · Skills](01-skills.png), [02 · MCP](02-mcp.png)                                             | Каталоги и состояние функций.                                                              |
| GUI       | [03 · Задача](03-task.png), [04 · Уточнение](04-follow-up.png)                                   | Два запуска одного диалога, инспектор инструментов.                                        |
| GUI       | [05 · Журнал](05-events.png), [06 · Статистика](06-statistics.png), [07 · Доктор](07-doctor.png) | Проверка событий, API usage и анализ сессии.                                               |
| GUI       | [08 · Eval](08-evaluation.png), [19 · Сводка A/B](19-gui-ab-report.png)                          | Запуск и итоговый отчёт по 30 попыткам.                                                    |
| GUI       | [09 · Рынок](09-market.png), [17 · Новинки](17-gui-market-news.png)                              | Установленный скилл, поиск и новинка в индексе.                                            |
| GUI       | [18 · Решение](18-gui-market-decision.png), [20 · Сравнение](20-gui-market-report.png)           | Отклонённая версия, 30 попыток и причины решения.                                          |

Отчёты агентов и журналы диалогов доступны в [материалах демонстрации](../demo/README.md). На отдельной реальной попытке доктор зафиксировал [две находки](../doctor/findings.txt).

# Проверки ДЗ №2

| Критерий               | Реализация и проверка                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Терминальный диалог    | Тест CLI проверяет подтверждение, отказ, уточнение в сохранённой сессии и статистику.                                                                                                |
| Каталог скиллов        | Три папки `skills/`. Тест загружает новую папку после повторного сканирования и проверяет изоляцию ошибки YAML.                                                                      |
| Выбор и загрузка       | Каталог передаёт названия и описания; модель получает полный Markdown через `load_skill`. Оценка проверяет активации отдельно от результата.                                         |
| Журнал и статистика    | У событий есть время, ID, session ID и run ID. Для сессии подсчитываются уникальные инструменты и скиллы, частоты, категории usage и выполненные MCP-вызовы.                         |
| MCP                    | Клиент получает список и схемы через SDK. Тесты проверяют настоящий stdio, результат, отказ по отдельному правилу доступа и таймаут.                                                 |
| Доктор                 | Сохранён отчёт по исторической сессии. Отдельные тесты проверяют два типа находок, похожие нормальные случаи и неполные журналы. [Правила и воспроизведение](doctor.md).             |
| Сравнение A/B          | Подготовлены три сценария, исходные данные, фиксированные правила и runner. Журнал, статистика и проверенный файл сохраняются на каждую попытку. [Протокол](evaluation-protocol.md). |
| Основная серия и вывод | 18 реальных запусков отложены. [Статус оценки](evaluation.md).                                                                                                                       |

`npm run check` запускает анализ кода, проверку форматирования, компиляцию и детерминированные тесты без LLM.

# Проверки ДЗ №2

Подробная матрица собрана в [чеклисте сдачи](../artifacts/checklist.md). Интерактивную часть можно повторить по [маршруту защиты](defense.md).

| Критерий            | Проверка                                                                                                                                                                                                                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Терминал            | `test/cli.test.ts` и `test/tui.test.ts` проверяют подтверждения, отказ, сохранение контекста, очередь и управление каталогами. [Скриншоты](../artifacts/screenshots/README.md).                                                                                                              |
| Скиллы              | `test/skills.test.ts` проверяет раскрытие описания и полной инструкции, проектный каталог `.agent`, отключение, повреждённый файл и симлинк.                                                                                                                                                 |
| MCP                 | `test/mcp.test.ts` и `test/mcp-manager.test.ts` проверяют реальные соединения, схемы, ограничение списка read-only функций, ошибку и таймаут.                                                                                                                                                |
| Доктор              | `test/doctor.test.ts` проверяет два правила и близкие нормальные случаи. [Наблюдения в реальном запуске](../artifacts/doctor/findings.txt).                                                                                                                                                  |
| Eval                | `test/eval.test.ts` проверяет артефакты и возобновление без повторного выполнения. [Все 30 попыток A/B](../artifacts/ab/report.md) и [протокол](evaluation-protocol.md).                                                                                                                     |
| Маркет и обновление | `test/cli-services.test.ts`, `test/market.test.ts` и `test/market-gate.test.ts` проверяют фоновое обнаружение, SHA-256, фиксацию версии при resume, принятие, отказ и откат. [Фоновый опрос](../artifacts/update/discovery/README.md) · [Реальное сравнение](../artifacts/update/report.md). |
| GUI                 | `test/gui.test.ts` проверяет сохранение настроек, сессию, события, подтверждения и откат через API локального интерфейса. [Как запустить](gui.md).                                                                                                                                           |

`npm run check` запускает линтер, форматтер, компиляцию и тесты. `node artifacts/verify.mjs` сверяет журналы, версии и SHA-256 из манифестов без доступа к модели.

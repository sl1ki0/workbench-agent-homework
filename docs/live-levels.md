## Подключение второго MCP

В чате можно добавить второй экземпляр учебного сервера. Используйте абсолютный путь к репозиторию.

```text
/mcp add tracker-demo {"command":"node","args":["/absolute/repo/dist/src/mcp/tracker-server.js"],"allowReadOnly":["list_tasks"],"timeoutMs":3000}
/mcp test
/mcp search filesystem
/mcp remove tracker-demo
```

Проверка устанавливает соединение и показывает разрешённые функции или ошибку. Поиск показывает совместимые записи реестра. Подключение и разрешённые функции задаются явно. [Спецификация API реестра MCP](https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/api/official-registry-api.md).

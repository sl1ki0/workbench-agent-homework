## Управление MCP в лайве

В чате можно добавить второй экземпляр учебного сервера. Подставьте абсолютный путь к репозиторию в аргумент.

```text
/mcp add tracker-demo {"command":"node","args":["/absolute/repo/dist/src/mcp/tracker-server.js"],"allowReadOnly":["list_tasks"],"timeoutMs":3000}
/mcp test
/mcp search filesystem
/mcp remove tracker-demo
```

`/mcp test` показывает результат MCP handshake, список разрешённых функций и ошибки соединения. Каталог реестра показывает описание и совместимые URL. Добавление выполняется отдельным явным действием. [Официальный API реестра MCP](https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/api/official-registry-api.md).

## Условия для реальных evals

Базовый и расширенный эксперименты можно выполнить до защиты, а на защите открыть сохранённые манифесты, сводку и пару A1/B1. Покажите артефакты, маршрутизацию и usage каждого варианта. Синтетический адаптер служит воспроизводимой проверке кода и процедуры отката. Статус реальной серии ведётся в [отчёте по eval](evaluation.md).

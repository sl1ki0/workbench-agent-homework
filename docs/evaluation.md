# A/B-эксперимент

Базовая команда `npm run eval -- run DIR` запускает три сценария и 18 попыток. Расширенная команда `npm run eval -- extended DIR` запускает пять сценариев и 30 попыток, добавляя сводку по неполным данным и обработку отказа настоящего MCP. Для каждой новой серии используйте пустой каталог. [Критерии и гипотеза](evaluation-protocol.md).

В материалах сдачи сохранены [основная серия](../artifacts/ab/report.md), [сравнение версий скилла](../artifacts/update/report.md) и [параметры модели](../artifacts/model.md). В `manifest.json` зафиксированы конфигурации и хеши входов, в `trials.jsonl` — одна строка на попытку. Журналы и файлы результата при его наличии лежат в `trials/`. Сводка разбирает пары A1/B1 по событиям.

```bash
npm run build
npm run eval -- report artifacts/ab
node artifacts/verify.mjs
```

Команды читают сохранённые материалы офлайн. Для новых вызовов `extended` и `resume` нужен настроенный модельный провайдер. `resume` проверяет исходный манифест и пропускает уже сохранённые попытки. Тесты стенда используют детерминированный адаптер и ведутся отдельно от модельного эксперимента.

При первоначальной пробе `workbench-qwen3:4b` три попытки дошли до лимита выходных токенов до первого вызова инструмента. Эта [архивная серия](evidence/ab-incomplete/report.md) сохранена отдельно и исключена из сводки приёмки.

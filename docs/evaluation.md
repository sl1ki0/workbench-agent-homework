# Статус A/B-эксперимента

Стенд, три сценария, автоматические проверки артефактов, журналирование и генератор сводки готовы. Реальная серия с 18 попытками пока не проведена. Статистика A/B и вывод о гипотезе появятся после неё. Протокол и команды воспроизведения находятся в [evaluation-protocol.md](evaluation-protocol.md).

Стенд сохраняет `manifest.json`, 18 строк в `trials.jsonl` и каталог каждой попытки с `result.json`, журналом и полученным артефактом. `report.md` строит сравнение по каждому сценарию, показывает расход с доступностью usage и разбирает пары A1/B1 по ID событий. Для нового эксперимента требуется пустой каталог. Частично собранные материалы можно посмотреть командой `report` с их каталогом.

Детерминированный `npm test` проверяет сам стенд при помощи тестового адаптера. Такие прогоны помечаются `mock` и не входят в результаты A/B.

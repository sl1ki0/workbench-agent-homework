# Статус A/B-эксперимента

Базовый стенд содержит три сценария и 18 попыток. Расширенный стенд содержит пять сценариев и 30 попыток. Команды `npm run eval -- run DIR` и `npm run eval -- extended DIR` запускают соответствующую серию и формируют Markdown-сводку. Критерии базовой версии описаны в [протоколе](evaluation-protocol.md). В расширенном наборе добавлены проверка списка закрытых задач MCP и расчёт сводки по независимому набору занятий.

## Реальный запуск Ollama

27 ноября 2026 года расширенная серия на `workbench-qwen3:4b` была остановлена после трёх завершённых попыток. Во всех трёх модель израсходовала 1024 выходных токена до первого вызова инструмента. Журналы содержат ошибку лимита, usage и уникальные идентификаторы. [Сохранённая неполная сводка](evidence/ab-incomplete/report.md).

После добавления совместимого переключателя `/no_think` один пробный прогон того же сценария снова достиг лимита 1024. Дополнительная проба с лимитом 2048 и температурой 0.6 также исчерпала лимит до первого инструмента. Эти пробы выполнялись отдельно от серии. В коротком интерактивном сценарии тот же профиль успешно вызвал `list_files` и вернул имя файла. Полная серия и вывод по гипотезе ещё предстоят.

## Артефакты и проверка кода

Стенд сохраняет `manifest.json`, строку на каждую попытку в `trials.jsonl`, журнал, файл результата при его наличии и проверки. `report.md` сравнивает A и B и разбирает пары A1/B1 по событиям. Для новой серии нужен пустой каталог. Для уже собранных материалов можно выполнить `npm run eval -- report DIR`.

`npm test` проверяет стенд с тестовым адаптером. Эти прогоны помечаются `mock` и исключаются из результатов A/B.

# Доктор сессии

`npm run agent -- doctor SESSION_ID` читает сохранённые JSONL из `.agent/events/`. В терминальном диалоге `/doctor` использует текущую сессию. `--state-dir PATH` принимает каталог состояния или каталог с копиями JSONL. `--json` возвращает отчёт со счётчиками, проверками и идентификаторами событий.

## Правила

- Повтор ошибки. В одном запуске два или больше разных идентификатора вызова имеют одинаковые инструмент, аргументы и текст ошибки. Успешный результат с теми же аргументами начинает новую серию. Подтверждённый отказ пользователя исключается. При совпадении доктор предлагает сначала проверить аргументы и условия повтора.
- Повтор чтения. Два или больше разных идентификатора вызова `read_file` вернули полное идентичное содержимое одного пути. Изменение файла между результатами, зарегистрированное в `workspace_changed`, начинает новую серию. Изменившийся текст также начинает новую серию. Совпадение помогает выявить кандидата на переиспользование результата, если свежесть данных допустима для задачи.

Отчёт показывает число разных совпавших вызовов, `run_id`, ID событий, интерпретацию и предложение. Состояние внешней среды между событиями может быть неизвестно. Повторное чтение может быть полезно для проверки свежести, а повтор ошибки может быть оправдан при нестабильном инструменте.

Модельные запросы и категории usage подсчитываются по журналу. Вход и выход уже включают соответствующие подкатегории кэша и рассуждений. Пропуски отмечаются как `partial` или `unknown`. Для доктора расход составляет 0 запросов и 0 токенов. Частоты инструмента берутся из предложений вызова, частоты MCP из событий начала исполнения. Повреждённые строки, отсутствие начала или конца запуска и недоступный usage отмечаются в отчёте.

## Разбор сохранённой сессии

Пробный запуск Qwen3:4b для задачи об исправлении скидки прервали во время третьего запроса к модели. В журнале зарегистрированы два действия с подтверждённым результатом, `list_files` и `read_file`. Для первых двух ответов API сообщил 1601 входной и 717 выходных токенов суммарно, из которых 551 входной токен обслужен из кэша. Для третьего запроса расход и длительность неизвестны. Правила доктора не нашли повторов в доступных событиях.

Отчёт получен офлайн из [исходного JSONL](evidence/doctor-real-source.jsonl). Доктор показал неполный usage и отсутствие события завершения запуска. [Отчёт JSON](evidence/doctor-real.json).

```bash
npm run agent -- doctor 947bf6f5-ea1b-48d5-87fb-1825b9e0e17b --state-dir docs/evidence
```

# Проверка ДЗ №1

Из корня репозитория выполните `npm ci` и `npm test`. Для запуска контрольного проекта из тестов нужны Bash и `python3`.

Детерминированные проверки используют временную копию исходного `workspace`. Тестовая модель возвращает заранее заданные сообщения OpenAI Chat Completions. Валидация, файловые операции, Bash и запись состояния работают через обычный runtime. Запуск с настоящей моделью отдельно проверяет выбор действий агентом.

В записанных локальных пробах Ollama модель ошибалась в реализации или завершалась по лимиту, поэтому результат ДЗ №1 показывается отдельным детерминированным тестом runtime. Он подтверждает успешный Bash, неизменность `test_order.py` и корректный `order.py`. [Вывод проверки](../artifacts/hw1/runtime-check.txt).

| Policy                                    | `test/workspace.test.ts`                                                                        | Команда и рабочая директория проверяются вместе. Отказ возвращается модели, файл сохраняет исходное содержимое.                                                                                                                  |
